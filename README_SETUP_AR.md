# نشر صفحات المصادر على GitHub Pages باسم القناة

1. سجّل دخول GitHub، واعمل منظمة مجانية: github.com/organizations/plan → Free → الاسم: theworldgauge
2. داخل المنظمة اعمل مستودع جديد Public باسم: theworldgauge.github.io
3. في المستودع: Add file → Upload files، واسحب كل محتوى مجلد site (index.html و .nojekyll ومجلد sources) ثم Commit.
4. Settings → Pages: تأكد أن Source = Deploy from a branch، الفرع main، المجلد / (root).
5. بعد دقيقة أو دقيقتين تفتح الروابط:
   - الصفحة الرئيسية: https://theworldgauge.github.io/
   - الجمعة السوداء: https://theworldgauge.github.io/sources/ep005/
   - اليابان: https://theworldgauge.github.io/sources/ep004/
6. بدّل رابط المصادر في وصف كل فيديو من YouTube Studio بالرابط الجديد.

إذا الاسم theworldgauge مأخوذ، اختر اسم ثاني وقل لي حتى أحدّث الروابط.
